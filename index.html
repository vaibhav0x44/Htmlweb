Computer is an electronic device that processes data according to instructions provided by software programs.
It takes input (data), processes it using a central processing unit (CPU), stores information, and produces output (results).

Computer Builds
  1. CPU: Heart of computer; data processing and system control are performed by the CPU.
  2. Monitor: Monitor is a display device that allows the user to see information and interact with the computer.
  3. Mouse: Mouse is used to click, drag, and drop objects on the display while interacting with the computer.
  4. Keyboard: Keyboard is used for giving input by the user. Users can type alphanumeric characters and commands.
Computer Generations
  1. Gen 1: First-generation computers were based on vacuum tubes and were very large and heavy.
  2. Gen 2: Second-generation computers worked using transistors.
  3. Gen 3: Third-generation computers worked using Integrated Circuit (IC) chips.
  4. Gen 4: Fourth-generation computers used microprocessors based on silicon chips.
  5. Gen 5: Fifth-generation computers focus on Artificial Intelligence (AI), smart sensors, and intelligent systems.
